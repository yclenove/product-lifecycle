## Step 1: 测试策略

**测试层次：**
- 单元测试：验证函数/方法逻辑
- 集成测试：验证模块间交互
- E2E 测试：验证用户场景
- 手动测试：验证 UX 和边界

## Step 2: 测试用例编写

**用例格式：**
```
ID: TC-模块-序号
名称: [简短描述]
优先级: P0/P1/P2
前置条件: [测试前需要满足的条件]
测试步骤:
  1. [步骤 1]
  2. [步骤 2]
预期结果: [期望的输出或行为]
```

## Step 3: 测试执行

**执行步骤：**
1. 确认测试环境就绪
2. 按优先级执行（P0 → P1 → P2）
3. 记录实际结果
4. 标记 Pass/Fail/Block
