# 国际化指南

## 多语言支持

product-lifecycle 的核心文档（SKILL.md、README.md、CHANGELOG.md）使用中文。
Agent prompt 使用中文，支持中文项目。

## 中文项目支持

### Agent prompt 中的中文友好

所有 Agent prompt 已支持：
- 中文项目名和描述
- 中文文档输出
- 中文搜索关键词（如 "用户反馈"、"竞品分析"）
- 中文代码注释建议

### 中文搜索关键词

| Agent | 中文搜索示例 |
|-------|-------------|
| 市场分析师 | "竞品分析"、"用户痛点"、"市场趋势" |
| 产品经理 | "用户需求"、"功能差距"、"创新灵感" |
| 反馈分析师 | "用户反馈"、"bug 报告"、"改进建议" |

### 英文项目支持

Agent prompt 同样支持英文项目：
- 搜索关键词自动适配（使用英文关键词）
- 文档输出可选英文
- 模板的占位符支持双语

## 多语言模板

每个模板的元数据表支持中英文：

```markdown
| 字段 | 值 |
|------|-----|
| 版本 / Version | v0.1 |
| 作者 / Author | 开发工程师 |
```

## 双语文档建议

如果项目需要英文文档：
1. 创建 `docs/en/` 目录
2. Agent prompt 中添加"输出语言：英文"指令
3. 模板保持中性（使用占位符而非硬编码中文）
