# 可访问性指南

## 文档可访问性

### Markdown 最佳实践

1. **标题层级**：使用正确的标题层级（h1 > h2 > h3），不跳级
2. **表格**：提供表格摘要，避免纯表格传达关键信息
3. **链接**：使用描述性链接文本，避免"点击这里"
4. **图片**：提供 alt 文本（如有图片）
5. **代码块**：标注语言类型

### 颜色无关

- 不仅用颜色传达信息（如状态用 ✓/✗ 而非仅红绿色）
- 表格中的状态同时使用文字和符号

### 结构清晰

- 使用列表而非长段落
- 关键信息前置
- 每个章节有明确标题

## Agent 输出可访问性

Agent 输出的文档应遵循上述规范。质量门禁检查：

- [ ] 标题层级正确
- [ ] 表格有摘要
- [ ] 链接描述性
- [ ] 状态用文字+符号
