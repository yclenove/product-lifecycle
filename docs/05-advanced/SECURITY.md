# 安全指南

## 项目安全考虑

product-lifecycle 本身是一个文档框架，不执行用户代码。但使用它构建的产品需要关注安全。

## Agent 输出的安全审查

Agent 可能生成包含以下安全风险的代码：
1. 硬编码凭证
2. 不安全的依赖
3. 缺少输入验证
4. 不安全的默认配置

质量门禁 Agent 负责检查这些风险。

## 安全检查工具集成

| 工具 | 用途 | 集成方式 |
|------|------|----------|
| npm audit | Node.js 依赖漏洞 | 开发阶段 |
| pip audit | Python 依赖漏洞 | 开发阶段 |
| trivy | 容器镜像扫描 | 部署阶段 |
| gitleaks | Git 密钥泄露 | CI/CD |
| semgrep | 静态安全分析 | CI/CD |

## 安全最佳实践

1. **永远不要在文档中硬编码凭证**
2. **使用 .env.example 而非 .env**
3. **质量门禁必须包含安全检查项**
4. **依赖更新定期执行**
