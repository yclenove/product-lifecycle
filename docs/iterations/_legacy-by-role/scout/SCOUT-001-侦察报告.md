## 附录：侦察方法

本次侦察使用以下方法：

1. **文件系统分析**：读取 README.md、CHANGELOG.md、SKILL.md、docs/、agents/、templates/、.claude/agents/ 目录
2. **内容对比**：对比 .claude/agents/ 与 agents/ 的文件数量和内容
3. **引用检查**：检查文档中的引用是否指向存在的文件
4. **一致性检查**：检查版本号、Agent 数量、搜索关键词的一致性
5. **模板覆盖检查**：检查 templates/ 是否覆盖所有 Agent 角色
