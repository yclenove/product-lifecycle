# 历史产物（按角色分类 · 只读）

本目录为 **v3.0 之前** 的归档方式：按 `market/`、`product/` 等角色类型分文件夹。

**v3.1 起** 新迭代请使用：

- 进行中 → [`../current/`](../current/)
- 已结束 → [`../<迭代ID>/`](../README.md)（如 `v1.8/`）
- 说明 → [`../README.md`](../README.md)

此处文件仅供回溯样本，**不要**再往这里写新内容。

如果你是第一次使用本技能包，请读 [`docs/01-getting-started/QUICK-START.md`](../../01-getting-started/QUICK-START.md)。
