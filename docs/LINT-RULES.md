# Lint 规则

## Agent Prompt Lint 规则

### 结构规则
| 规则 | 说明 | 严重度 |
|------|------|--------|
| 必需章节 | 每个 agent 必须有：职责、任务、输出、质量门禁、上下文管理 | 错误 |
| 章节顺序 | 职责 → 任务 → 输出格式 → 质量门禁 → 上下文管理 | 警告 |
| 占位符 | 使用 `{{PROJECT_NAME}}` 和 `{{PROJECT_DESCRIPTION}}` | 信息 |

### 内容规则
| 规则 | 说明 | 严重度 |
|------|------|--------|
| 输出预算 | 每个 agent 必须指定输出字数预算 | 警告 |
| 质量门禁 | 每个 agent 必须有可检查的门禁项 | 错误 |
| 示例 | 建议包含至少一个输出示例 | 信息 |

## 模板 Lint 规则

### 结构规则
| 规则 | 说明 | 严重度 |
|------|------|--------|
| 元数据表 | 必须有：版本、作者、日期、状态、关联文档 | 错误 |
| 必填标记 | 章节必须标注 [必填] 或 [可选] | 警告 |
| 修订记录 | 必须有「修订记录」章节 | 错误 |
| 使用示例 | 建议有 <details> 折叠示例 | 信息 |

## 文档 Lint 规则

### 链接规则
| 规则 | 说明 | 严重度 |
|------|------|--------|
| 断链 | 所有文件路径引用必须指向存在的文件 | 错误 |
| 锚点 | 章节引用必须指向存在的章节 | 警告 |
| 外部链接 | 外部链接建议使用 HTTPS | 信息 |

### 格式规则
| 规则 | 说明 | 严重度 |
|------|------|--------|
| 标题层级 | 不跳级（h1→h2→h3） | 警告 |
| 表格 | 表格必须有表头 | 错误 |
| 代码块 | 代码块必须标注语言 | 信息 |
