## 7. 版本策略

### 7.1 版本号选择


| 选项         | 说明                        | 选择               |
| ---------- | ------------------------- | ---------------- |
| v1.4.1     | patch：仅修复 bug             | 不选——包含新功能（模板、指引） |
| **v1.5.0** | **minor：新功能 + 改进，无破坏性变更** | **选定**           |
| v2.0.0     | major：破坏性变更               | 不选——无 API 破坏     |


**理由：** v1.5 引入了新模板、新文档和渐进式采用指引，属于功能增强，符合 minor 版本语义。

### 7.2 CHANGELOG 格式

遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/) 规范：

```markdown
## [1.5.0] - 2026-05-10

### Added
- .claude/agents/: 补全 6 个缺失的 subagent 定义（product-manager, devops, docwriter, proactive-scout, feedback-analyst, iteration-planner）
- templates/scout_template.md: 需求侦察兵专用模板
- templates/quality_report_template.md: 质量门禁专用模板
- docs/CONTEXT-MANAGEMENT.md: 上下文管理最佳实践
- SKILL.md: 渐进式采用指引（核心 Agent 子集 + 精简模式）

### Fixed
- 补充 v1.4.0 CHANGELOG 记录（Subagent 定义 + 动态上下文注入）
- 搜索关键词年份更新：2025 -> 2026
- 修复 workflow_plan_template.md 编号重复（两个 1.2）

## [1.4.0] - 2026-05-03

### Added
- .claude/agents/: 正式 Subagent 定义（6 个核心 Agent）
- 动态上下文注入：自动检测项目结构、技术栈、Git 状态
```
