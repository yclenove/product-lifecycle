## 1. 背景与问题陈述

用户在采用 product-lifecycle 做迭代时，期望看到 **与 Agent 角色一一对应的产出**，以便对照 `WORKFLOW_PLAN`、做审计与多会话接力。v1.6 已增强文档与 subagent，但**执行层仍依赖使用者自觉分角色**。

---

## 2. 用户故事（本轮必须）

| ID | 用户故事 | 验收标准（Given/When/Then） |
|----|----------|-----------------------------|
| US-001 | 作为 **技能包维护者**，我希望 **一次迭代在 docs/ 中有可区分的角色产出**，以便 **grep 文件名即可还原谁做了什么**。 | Given 已选定模式 B，When 完成一轮「规划型迭代」，Then `docs/` 中存在侦察/反馈/市场/产品/架构/开发/测试/门禁中**至少 6 类**独立文件或经 ROLE-RUN-LOG 索引的等价物。 |
| US-002 | 作为 **Cursor 用户**，我希望 **文档明确分角色落盘约定**，以便 **复制工作流到业务仓**。 | Given 阅读 `docs/SKILL-CURSOR.md` 或 WORKFLOW_PLAN，When 查找「分角色」，Then 能读到**落盘命名与最小集合**说明。 |
