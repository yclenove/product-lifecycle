# docs/archive/ — 历史运行产物

本目录归档**早期迭代过程中产生的角色输出产物**，**不是使用文档**。

保留的目的是：
- 作为各角色产出物的真实样本（看格式怎么写）
- 项目演进的历史记录
- 必要时回溯

如果你是第一次使用本技能包，**不需要读这里的任何文件**。请直接看 `docs/QUICK-START.md`。
