AI 与模型

LLM

大语言模型，如 Claude、GPT、Gemini。

Token

模型计费与上下文的最小单位；中文约一字一词。

Context / 上下文

当前对话可见的全部内容，有上限。

Prompt

给模型的指令；角色 prompt 常为数百至数千字。

Hallucination / 幻觉

模型编造不存在的事实；用模板与文件引用缓解。

Streaming / 流式

逐块返回 SSE；中转超时会出现 chunked read 错误。

Compact

Claude Code 压缩历史上下文（/compact）。

Subagent / 子代理

主会话派发的独立上下文工作者。

Harness

运行 skill/agent 的宿主环境（Claude Code、Cursor 等）。
