7.4 微服务配方

服务拆分、事件驱动、可观测性——架构师与 DBA、运维权重更高。

推荐 Agent

编排 → 产品（边界用例）→ 架构师 → DBA → 后端工程师（可按服务并行 subagent）→ 安全 → DevOps → QA → 门禁

架构产出应包含

  • 服务清单与职责、同步/异步边界
  • 时序图（下单、支付等关键路径，建议 drawio）
  • 数据所有权（每服务一张表）
  • 分布式事务 / Saga / 幂等策略
  • 可观测：日志关联 ID、指标、追踪
