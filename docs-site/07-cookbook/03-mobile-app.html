7.3 移动应用配方

iOS / Android / 跨端（Flutter、RN）——UI 与前后端契约要更早对齐。

推荐 Agent

编排 → 产品 → UI/UX 设计师（原型、设计令牌）→ 架构师（API + 离线策略）→ 前端工程师（若 H5/跨端）或 开发工程师 → QA（真机/兼容性）→ 门禁

架构要点

  • API 版本与向后兼容
  • 推送、深链、应用商店审核清单
  • 离线缓存与冲突解决
  • 性能：首屏、包体积、图片策略

测试

测试经理需覆盖：多机型、弱网、权限弹窗、前后台切换。自动化可结合 Maestro / Detox 等（在 DEV 文档写明）。
