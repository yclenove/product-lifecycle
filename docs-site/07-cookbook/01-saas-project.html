7.1 SaaS 项目配方

多租户、订阅计费、权限与审计——典型 B2B SaaS 的 Agent 子集与顺序建议。

推荐 Agent 子集

模式 A（0→1）：编排 → 市场 → 产品 → UI → 架构 → DBA → 前端 + 后端（可并行）→ 安全 → QA → 门禁 → 运维 → 文档

模式 B（迭代）：侦察 + 反馈 → 市场 → 产品 → 迭代规划 → 架构（影响分析）→ 开发 → QA → 门禁

关键产出

  • PRD：租户模型、套餐、RBAC
  • ARCH：服务边界、鉴权、审计日志、数据隔离
  • 安全工程师：STRIDE、OWASP 清单
  • 数据分析师：北极星指标、漏斗（可选）

注意点

  • 尽早定多租户策略（库级 / schema / 行级），避免开发后期推翻
  • 支付、邮件等第三方用 MCP 或明确 mock 边界
  • 不要一次跑满 20 Agent；MVP 用 6–8 个角色即可
