7.2 内部工具配方

面向公司内部、用户量可控、重集成现有系统——可大幅缩短市场与 UI 阶段。

精简链路

编排 → 产品经理（需求 + 用户故事）→ 架构师 → 开发工程师 → 测试经理 → 质量门禁

通常跳过：市场分析师（除非要对外对标）、需求侦察兵（除非要主动扫描）。

典型场景

  • 运营后台 / 审批流
  • 报表与数据导出
  • 对接 LDAP、企业微信、内部 API

文档侧重

  • 权限矩阵（谁能在什么页面做什么）
  • 与遗留系统的接口契约
  • 运维：内网部署、无公网 SLA 的监控项
