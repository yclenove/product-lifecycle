6.1 自定义已有 Agent

改真源 agents/<role>.md，再同步到 Claude Code；不要直接改 .claude/agents/（会被脚本覆盖）。

正确流程

  1. 编辑 agents/developer.md（示例）
  2. 调整输出预算、技术栈约束、必读的 docs 路径
  3. 运行 bash scripts/sync-agents.sh developer（或全量无参数）
  4. 若在 Cursor 业务项目装了 subagent，重新运行 install-cursor-subagents.ps1

可改什么

  • 任务步骤与检查清单
  • 推荐引用的 skills/ 方法论
  • 产出模板路径（templates/）
  • 「应该画的图」列表

不建议改什么

  • .claude/agents/*.md 手写内容（有 AUTO-GENERATED 标记）
  • 编排总监的「通过 /pl 激活」语义（避免又被当成普通子代理）

模型分级：bash scripts/configure-models.sh · 见 docs/04-reference/MODEL-CONFIG.md
