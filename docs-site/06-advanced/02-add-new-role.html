6.2 新增一个角色

新增 Agent = 新 prompt 真源 + 模板 + sync-agents 注册 + 文档站角色页（可选）。

检查清单

  1. 在 agents/ 新建 my-role.md（参考同层角色结构）
  2. 在 templates/ 添加 my_role_template.md
  3. 编辑 scripts/sync-agents.sh：在 DESCRIPTIONS、TOOLS 各加一行
  4. 运行 bash scripts/sync-agents.sh my-role
  5. 更新 docs-site/assets/nav-data.js 与 04-roles/（或跑 generate-docs-site.sh）
  6. 在 agents/orchestrator.md 工作流里加入该角色的调用时机
命名 文件名用 kebab-case，与 subagent_type / @name 一致，如 security-auditor。

产出路径约定：docs/04-reference/OUTPUT-PATHS.md
