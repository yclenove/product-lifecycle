6.4 CI/CD 集成

CI 跑确定性检查（lint、测试、模板校验）；AI 角色仍在开发阶段产出文档与代码，发布前由流水线兜底。

可接入的脚本

# 质量与结构校验
bash scripts/validate.sh
bash scripts/validate-templates.sh
bash scripts/lint-prompts.sh

# Agent 冒烟（可选）
bash scripts/test-agents.sh

GitHub Actions 示例

name: quality
on: [pull_request]
jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: bash scripts/validate.sh

与质量门禁的关系

质量门禁 Agent 产出人工可读的审查报告；CI 的 validate.sh 做机器可判定的规则。两者互补，不互相替代。

仓库已有 .github/workflows/，可按团队规范扩展。
