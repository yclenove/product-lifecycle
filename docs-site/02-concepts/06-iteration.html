2.6 迭代与长程模式

一轮迭代 = 从需求到可交付的一圈；长程模式 = 多天/多 session 不丢上下文。

目录约定

  • docs/iterations/current/ — 当前迭代产出（PRD、ARCH、图…）
  • docs/iterations/<ID>/ — 归档后的历史迭代
  • docs/07-long-running/STATE.md — 跨 session 状态
  • docs/07-long-running/HANDOFF.md — 下线前的移交单

常用脚本

bash scripts/init-iteration.sh myapp-v1.1
bash scripts/checkpoint.sh product-manager "PRD 定稿"
bash scripts/handoff.sh
bash scripts/resume.sh

每个 Agent 的 Step 0

启动时先读 STATE.md，结束前更新「已完成 Agent」与「下一步」。这样换天、换电脑也能接着干。
