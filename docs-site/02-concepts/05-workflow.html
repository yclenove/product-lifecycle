2.5 工作流编排

编排总监根据项目状态选择模式，决定调用哪些 Agent、顺序与并行关系。

三种模式

模式何时典型链路
A · 从 0 到 1无代码、无 PRD市场 → 产品 → UI → 架构 → 开发 → QA → 门禁
B · 迭代已有产品，新需求/反馈反馈/侦察 → 产品 → 规划 → 开发 → QA
C · 长程恢复跨 session 续做读 STATE.md → 从上次 Agent 继续

WORKFLOW_PLAN

复杂项目由编排总监产出 WORKFLOW_PLAN-*.md（模板：templates/workflow_plan_template.md），写明每步 Agent、依赖、并行与门禁。

并行示例

  • 架构定稿后：前端 + 后端可并行（都读 ARCH）
  • 开发进行中：测试经理可提前写测试计划（读 PRD）
  • 安全工程师可与开发后期并行做威胁建模

详见 agents/orchestrator.md 与 docs/03-workflow/。
