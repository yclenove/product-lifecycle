  • 异常访问告警
  • 密钥泄露检测
  • 依赖漏洞扫描

部署容错

部署失败处理

  • 1. 健康检查失败 → 自动回滚到上一版本
  • 2. 启动超时 → 检查日志，修复后重试
  • 3. 端口冲突 → 修改配置或停止冲突服务
  • 4. 依赖不可用 → 检查网络/配置，重试
