product-lifecycle 文档

20 个专业 AI 角色协作，把一个想法变成上线产品的完整生命周期框架。 本文档不预设认知门槛 —— 从「Agent 是什么」到「怎么自定义」都有。

👋 你是第一次来吗？ 建议按顺序读：这是什么 → 心智模型 → 什么是 Agent → 5 分钟跑通。 大约 20 分钟读完，可以开始动手做项目。

这是什么？

一句话：让 AI 像一个完整的产品团队那样工作。

现在用 AI 写代码（Claude Code、Cursor、Copilot）很容易，但只能干"实现"这一段。 真实做产品要走完：市场分析 → 产品需求 → UI 设计 → 架构 → 开发 → 测试 → 部署 → 反馈 → 下一轮迭代。 每一段需要不同专业。一个通用 AI 助手没法都做好。

product-lifecycle 把这条流水线拆成 20 个专业角色， 每个角色有自己的工作提示（prompt）、文档模板、必画的图、质量门禁。 AI 按角色切换身份干活，产出比"光让它写代码"高几个量级。

3 分钟开干

Claude Code

# 1. 装到 ~/.claude/skills/
git clone https://github.com/yclenove/product-lifecycle.git ~/.claude/skills/product-lifecycle

# 2.（可选）一键安装方法论 skill
npx superpowers-zh

# 3. 在 Claude Code 里
> /product-lifecycle myapp "做一个 SaaS 协作平台"

Cursor

# 1. clone 到项目根目录
git clone https://github.com/yclenove/product-lifecycle.git .product-lifecycle

# 2. 把 .product-lifecycle/.cursor/agents/ 拷到你项目的 .cursor/agents/

# 3. 在 Cursor 中用 @orchestrator 启动

详细步骤见 3.1 / 3.2。
