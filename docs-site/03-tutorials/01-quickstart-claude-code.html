3.1 Claude Code 5 分钟

装技能包 → 可选装方法论 skill → 一条命令启动编排。

1. 安装技能包

git clone https://github.com/yclenove/product-lifecycle.git ~/.claude/skills/product-lifecycle

2.（可选）画图 MCP

方法论 skill 已内置在 skills/，无需再装 superpowers-zh。仅需画图时：

bash ~/.claude/skills/product-lifecycle/scripts/install-mcp.sh

3. 在业务项目里启动

cd /path/to/your-app
claude
> /product-lifecycle myapp "一句话描述你的产品"
