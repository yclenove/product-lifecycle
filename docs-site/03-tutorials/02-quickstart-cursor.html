3.2 Cursor 5 分钟

装技能包 → 解析 PACKAGE_ROOT → 在业务项目里用 Subagent 或 Read 扮演角色。Cursor 没有 Claude Code 的 /pl 斜杠命令，但流程可以对齐。

📍 前置阅读 这是什么 · 什么是 Agent

1. 全局安装技能包

# Windows PowerShell
git clone https://github.com/yclenove/product-lifecycle.git "$env:USERPROFILE\.cursor\skills\product-lifecycle"

# 建议设置环境变量（避免路径歧义）
[Environment]::SetEnvironmentVariable("PRODUCT_LIFECYCLE_ROOT", "$env:USERPROFILE\.cursor\skills\product-lifecycle", "User")

2. 在新业务项目里安装 Subagent（推荐）

Cursor 不会在你打开新项目时自动写入 .cursor/agents/，需要手动执行一次：

cd H:\path\to\your-app
$env:PRODUCT_LIFECYCLE_ROOT = "$env:USERPROFILE\.cursor\skills\product-lifecycle"
pwsh -File "$env:PRODUCT_LIFECYCLE_ROOT\scripts\install-cursor-subagents.ps1" -Target .

完成后可在 Agent 输入框使用 @orchestrator、@developer 等调用各角色。

3. 轻量用法（不装 Subagent）

在对话里让 AI 读取真源 prompt 并扮演角色：

你是编排总监。PACKAGE_ROOT 在 %USERPROFILE%\.cursor\skills\product-lifecycle
请先 Read agents/orchestrator.md，再为当前项目制定 WORKFLOW_PLAN，产出写到本仓库 docs/
