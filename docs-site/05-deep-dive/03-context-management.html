5.3 上下文管理

上下文 = 模型当前能「看见」的全部对话与工具结果。多 Agent 协作时，管理不好会导致断流、失忆和费用飙升。

分层读取（L0–L3）

层级内容何时读
L0SKILL.md 模式选择每次启动
L1WORKFLOW_PLAN / STATE 摘要每个 Agent 启动
L2PRD/ARCH 相关章节需要细节时
L3全文 + 大段代码极少

摘要传递

上游产出 3000 字文档 → 在计划里写 300 字摘要 → 下游默认只读摘要，按需展开原文。

实践技巧

  • 用 Grep 定位章节，避免 Read 整个仓库
  • 全量 20 Agent 前先做 /compact 或开新 session
  • 项目级 MCP 只加载需要的（勿全局挂 99 个 MySQL 工具）
  • 长程用 STATE.md，不要每轮重读所有历史 PRD
