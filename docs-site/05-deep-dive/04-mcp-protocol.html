5.4 MCP 协议深入

MCP（Model Context Protocol）让 AI 以统一方式调用外部工具：数据库、画图、浏览器等。每个 MCP server 会向客户端注册一批 tool。

在本项目中的用法

仓库根 .mcp.json 默认启用 drawio MCP，供架构师、产品经理等画正式交付图：

{
  "mcpServers": {
    "drawio": {
      "command": "npx",
      "args": ["-y", "@next-ai-drawio/mcp-server@latest"]
    }
  }
}

工具数与性能

全局挂载大型 MCP（如 mysql-mcp-server 约 99 个 tool）会让每次请求都带上巨大 tool schema，加剧上下文与断流风险。建议：

  • 按项目配置 .mcp.json，需要数据库的项目再加 MySQL MCP
  • 保持全局 ~/.claude/settings.json 的 mcpServers 尽量空

安装 drawio（任意项目）

bash scripts/install-mcp.sh   # 或 install-mcp.ps1
