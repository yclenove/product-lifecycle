5.2 Prompt 工程基础

本项目的 20 个 agents/*.md 就是 20 份「生产级 prompt」：身份、步骤、产出格式、禁忌一并写清。

好 prompt 的四个块

块作用本项目示例
身份固定角色与边界「你是 XX 的架构师」
输入读哪些文档、用什么工具必读 PRD、可选 drawio MCP
步骤可执行 checklistStep 0 恢复上下文 → 设计 → 产出 ARCH
输出模板 + 字数预算templates/architecture_template.md

为什么要模板

自由散文难以被下游 Agent 解析。模板强制章节（背景、方案、风险、决策记录），便于 grep 与摘要传递。

常见反模式

  • 「你是全能专家」→ 角色漂移
  • 无输出上限 → token 浪费、中转超时
  • 不引用真实文件路径 → 幻觉路径与 API
  • 在子代理里重复读 5 个 skill → 已用 SUBAGENT_GUARD 短路（v3.4+）
