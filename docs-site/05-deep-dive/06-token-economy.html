5.6 Token 经济学

Token 既是成本单位，也是上下文上限。全量 20 Agent + 149 个 tool 定义 + 8 万 input，很容易在中转层 2 分钟左右断流。

主要消耗来源

  • 对话历史累积（每轮 tool 结果都进上下文）
  • 工具 schema（tool 越多，每请求越大）
  • 全文 Read 大文档 / 大仓库
  • 子代理重复初始化（v3.4 已用 SUBAGENT_GUARD 缓解）

各角色输出预算（参考）

角色建议字数
编排总监 / 架构师~3000
产品 / 市场~2000–2500
开发 / 测试 / 其他~1500–2000

省钱与稳态建议

  1. 用 /pl 选精简模式，不要默认全量
  2. 移除不必要的项目级 MCP（如未用的 mysql-mcp-server）
  3. 大 session 定期 /compact 或新开对话
  4. 长程迭代用 STATE 摘要，勿重复读全部 iterations 历史
  5. 网关不稳时，大上下文走长上下文专线模型（见 FCC 路由配置）
