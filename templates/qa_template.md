### 示例：用户注册功能测试计划

**测试范围：** PRD-001 §3.1 用户注册

**测试用例矩阵：**

| ID | 模块 | 用例名称 | 优先级 | 前置条件 | 测试步骤 | 预期结果 |
|----|------|----------|--------|----------|----------|----------|
| TC001 | 注册 | 正常注册 | P0 | 无 | 输入有效邮箱+密码，点击注册 | 账号创建成功，跳转首页 |
| TC002 | 注册 | 邮箱重复 | P0 | 邮箱已注册 | 输入已注册邮箱，点击注册 | 提示"邮箱已注册" |
| TC003 | 注册 | 密码过短 | P0 | 无 | 输入 6 位密码，点击注册 | 提示"密码至少 8 位" |
| TC004 | 注册 | 邮箱格式错误 | P1 | 无 | 输入 "abc"，点击注册 | 提示"邮箱格式不正确" |
| TC005 | 注册 | 并发注册 | P1 | 无 | 同一邮箱同时提交两次 | 仅一个成功，另一个提示重复 |

**质量门禁：**
- P0 用例通过率 = 100%
- 代码覆盖率 >= 80%
- 无阻塞级 Bug
